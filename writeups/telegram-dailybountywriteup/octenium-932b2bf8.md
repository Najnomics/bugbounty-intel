Dès que vous achetez un plan **d'hébergement site Web**, Octenium ( Hébergement web Algérie ) stocke votre site sur un de nos serveurs et l'affecte à DNS unique. Le DNS sert d'adresse aux utilisateurs du monde entier pour trouver et parcourir votre site Web.

Cette adresse unique est requise pour pouvoir afficher votre site. En achetant un pack d'hébergement de site Web, vous acquérez en fait un espace sur un de nos serveurs. Cet espace est similaire à celui du disque dur d'un ordinateur, mais le serveur permet d'accéder aux fichiers de votre site Web depuis n'importe où.

Nous proposons des différents plans d'hébergement. Lequel vous convient le mieux dépend de ce que vous voulez faire avec votre site ; par exemple, créer un panier, un blog ou un podcast avec une application Web spécifique. 

Si vous ne savez pas lequel choisir, appelez le support technique Octenium.

Le processus de transfert de votre site Web vers Octenium est trés simple. Si vous avez accès aux fichiers de votre site Web existant, vous pouvez les charger grâce à notre cPanel ou par le biais d'un client FTP. 

Si vous ne disposez pas d'une copie actuelle de votre site Web, vous devriez pouvoir en obtenir une auprès de votre fournisseur d'hébergement actuel. On prends en charge et sans frais les transferts de vos sites webs en tout genre.

Il vous faut tout d'abord activer votre compte. Allez sur octenium.com ( Hébergement web Algérie ) et cliquez sur Mon compte. puis cliquez sur le lien "Connexion au cPanel", Il vous est demandé de saisir votre nom d'utilisateur et votre mot de passe. Une fois connecté, vous voyez une liste de services, chargez vos pages html via le Gestionnaire des fichiers..

Nos plans permettent l'hébergement de plusieurs sites Web. Vous pouvez également utiliser ces plans pour configurer plusieurs noms (alias) pour votre site et diriger les visiteurs vers certaines pages spécifiques.
