**“بسم الله الرحمن الرحيم”**

First of all, the Exam is not as Easy as Everyone says, The exam is very short, ’10 hours’, with a very big scope, 10+ webapps that you have to do a full penetration test on, not just catch the flag. It’s not a CTF! You need to prepare a note app and document all of your findings. You have to start with recon, do an Nmap scan, and use directory brute-force and attack surface discovery and search for vulnerabilities and exploit them for all those webapps in only 10 hours!. It takes a lot of Time that you don’t have!

And because there are many webapps and functions, parameters, endpoints, and APIs, you will get lost, and a lot of time will be wasted on literally nothing but headache and noise (ask me because it happened to me -\_-)

So first of all, stay calm. Start webapps 1 by 1, do your recon and directory fuzzing, and start mapping the attack surface and document all the webapps 1 by 1 with every small detail (trust me, you will need it later). Don’t test for any vulnerabilities. Finish the Recon process, then start testing webapps 1 by 1.

Before using any tool, use -h and -man to know the version of the tool, cuz if it’s an old version, most of the commands won’t work, and you will waste a lot of time (especially Hydra).

Read the Letter of Engagement Very well cuz it simulates real-world pentesting process and it has instructions for the exam itself (don’t deal with it the same way as CTF challenges cuz it’s not. DOCUMENT EVERYTHING!)

The exam has all the Vulnerabilities addressed in the eWPT course, such as LFI, RFI, CMS Hacking, reflected XSS, Stored XSS, SQLI, Authentication bypass, path traversal, broken access control, information disclosure, Web Service Security Testing, HTTP method tampering, and you have to test all of that in +10 webapps in only 10 hours , not Easy, huh? :)

And last but not least, stay calm, pick targets 1 by 1, test for everything you learned, Document all of your Findings, and Happy Hacking :)
