## Capture the moment. Share the full story.

Record bugs, feedback, and ideas in one Jam that keeps the moment and available technical context together for teammates or agents.

### Capture feedback as it happens

Record your screen or capture a screenshot with the Chrome extension, so the feedback is ready to share while the details are still fresh.

### Automatic AI summary

Jam AI automatically suggests a title, summary, and repro steps that give developers and agents a clear place to start.

### Attach technical context automatically

Jam keeps available logs, network requests, user events, and device details with the recording, so engineers and agents can start investigating.

### Send the Jam to your tools

Route the Jam to Linear, Jira, or Slack for team triage, or into your AI tooling so a coding agent can investigate and ship the fix.

##### Browser extension

Capture bugs, feedback, and ideas without leaving your browser.

## Context for agents. Proof for humans.

Jam MCP lets agents read the context in a Jam. Jam CLI lets agents create Jams to show their work.

##### Webhooks

### Turn new Jams into agent runs

Use webhooks to trigger your agent, then let Jam MCP pull the context it needs to investigate and ship the fix.

##### MCP

### Give agents the context to fix issues

Jam MCP brings the recording and technical context into your coding agent, so it can investigate with the full story.

\~/my-app

$

`jam create jam  '{`   

"kind": "video",  

"videoPath": "./artifacts/pr-12911.mp4",   

"title": "PR #12911 walkthrough",  

"url": "https://github.com/acme/app/pull/12911",   

"screenDimensions": {"width": 1920, "height": 1080} 

}'

### Make agent work easy to review

NEW

Use Jam CLI to publish agent-made videos as Jams that show the work behind a PR, walkthrough, or product explainer.
