# BBP vs VDP

- Bug Bounty Program (BBP): ແມ່ນໂຄງການ ຫຼື ໂປຣແກຣມທີ່ເປີດໃຫ້ເຮົາສາມາດເຂົ້າໄປຫາຊ່ອງໂຫວ່ໄດ້ແບບຖືກກົດໝາຍແຕ່ຕ້ອງເບິ່ງຕາມເງື່ອນໄຂ Policy ຂອງແຕ່ລະໂປຣແກຣມເຊິ່ງຈະແຕກຕ່າງກັນໄປຕາມແຕ່ລະໂປຣແກຣມ ຜົນລັບຂອງການເຮັດ BBP ຖ້າຫາກວ່າເຮົາພົບຊ່ອງໂຫວ່ແລ້ວແຈ້ງໃຫ້ເຈົ້າຂອງໂປຣແກຣມຮັບຮູ້ ເຮົາຈະໄດ້ເງິນເປັນລາງວັນຕອບແທນ

- Vulnerability Disclosure Program (VDP): ຄືກັນກັບ BBP ທຸກຢ່າງຍົກເວັ້ນຈະບໍ່ໄດ້ລາງວັນເປັນເງິນແຕ່ຈະໄດ້ເປັນຢ່າງອື່ນແທນເຊັ່ນ: ມີຊື່ໃນ Hall of Fame, ໄດ້ Swag, Letter, Credit… ເຊິ່ງ Credit ທີ່ໄດ້ແມ່ນຈະສາມາດເອົາໄປຕໍ່ຍອດເພື່ອເຂົ້າ Private BBP/VDP ໄດ້, ແລະ VDP ສ່ວນໃຫຍ່ຈະແມ່ນອົງກອນລັດທະບານ, ມະຫາວິທະຍາໄລ, ແລະ ອື່ນໆ…

ທັງ BBP ແລະ VDP ແມ່ນຈະມີບາງໂປຣແກຣມທີ່ໃຫ້ CVE ນຳ, ແລ້ວເຮົາສາມາດເຂົ້າຮ່ວມໂປຣແກຣມເຫຼົ່ານີ້ໄດ້ຈາກໃສແດ່? ສ່ວນໂຕແມ່ນຈະປັກຫຼັກຢູ່ Hackerone, BugCrowd, YesWeHack ແລະ ກັບເຈົ້າຂອງ product ທີ່ເປີດເອງໂດຍຕົງ.

Note: ຫຼາຍໆຄົນຈະເວົ້າວ່າຂ້ອຍແຮັກ NASA ແຕ່ຄວາມຈິງແລ້ວທີ່ຂ້ອຍແຮັກແທ້ໆແມ່ນຊັບໂດເມນ mars ຂອງ NASA ເຊິ່ງ mars ແປວ່າ ດາວອັງຄານ, ແມ່ນແລ້ວທີ່ຈິງຂ້ອຍແຮັກດາວອັງຄານ 5555555555.

ສຳຫຼັບຄົນທີ່ໄດ້ອ່ານໂພສທີ່ຂ້ອຍໄດ້ແປະໄວ້ເທິງສຸດໄປແລ້ວຈະເຫັນວ່າຊ່ອງໂຫວ່ທີ່ຂ້ອຍເຈີແມ່ນ **Unautenticated SQL Injection** ທີ່ມີຄວາມຮຸນແຮງລະດັບສູງສຸດ (P1 — Critical), ທີ່ມັນຮຸນແຮງເພາະວ່າສາມາດຍິງໄດ້ໂດຍທີ່ບໍ່ຕ້ອງຜ່ານເງື່ອນໄຂຫຍັງເລີຍແຄ່ເຂົ້າເວັບໄຊ້ໄປແລ້ວຍິງ ແລ້ວກະໄດ້ເລີຍ ເຊິ່ງມັນບໍ່ຄວນທີ່ຈະຫຼົງເຫຼືອຢູ່ໃນຍຸກປັດຈຸບັນແຕ່ຂ້ອຍກະບໍ່ເຂົ້າໃຈຄືກັນວ່າເປັນຫຍັງມັນຄືຍັງຫຼົງເຫຼືອຢູ່ເພາະວ່າຈຸດອື່ນໆເປັນພັນຈຸດແມ່ນຈະຖືກ WAF ກັນໄວ້ໝົດຍົກເວັ້ນຈຸດນີ້ ມັນແປກສຸດໆ ແນ່ນອນວ່າທຳອິດຂ້ອຍບໍ່ຄິດທີ່ຈະມາຫາຕາມຈຸດເຫຼົ່ານີ້ດອກ ເພາະຄິດວ່າມັນຄືຊິບໍ່ເຫຼືອຫຍັງແບບນີ້ໃຫ້ເຮົາແລ້ວ ຄົນທີ່ພະຍາຍາມຫາຢູ່ກະເປັນລ້ານ ຫຼື ຍ້ອນທຸກຄົນກະຄິດແບບດຽວກັນແນວນີ້ໝົດເບາະເລີຍເຮັດໃຫ້ຂ້ອຍຫາຈຸດນີ້ເຈີ… ນັ້ນແຫລະ ເລີຍເປັນທີ່ມາວ່າເປັນຫຍັງຂ້ອຍຈັ່ງບອກວ່າ ຂ້ອຍແຄ່ໂຊກດີ ເຊິ່ງມັນແມ່ນຄວາມຈິງ ເຖິງມັນຈະບໍ່ແມ່ນຊ່ອງໂຫວ່ທີ່ສັບຊ້ອນຫຍັງແຕ່ກະຢ່າເຖາະ ເພາະສຸດທ້າຍແລ້ວຂ້ອຍໄດ້ LOR ມາຂິງເຊິ່ງຄາດວ່າໜ້າຈະແມ່ນຄົນລາວຄົນທຳອິດທີ່ໄດ້ມາ ແມ່ນບໍວະ 555555, ສຳຫຼັບໃຜທີ່ກຳລັງຫາຢູ່ກະສູ້ຕໍ່ໄປເຖິງວ່າລະບົບຈະຂ້ອນຄ້າງນິ້ງແລ້ວ ບໍ່ຄ່ອຍໄດ້ອັບເດດຫຍັງເພີ່ມເຕີມແລ້ວ ແຖມ scope ກະໜ້ອຍລົງເລື້ອຍໆ ໃນແຊັດຕາມ Commumity ມັກຈະມີຄົນເວົ້າວ່າ ***“Most peeps don’t realize the more time passed on this program the harder it is to find a bug”*** ເຊິ່ງຂ້ອຍກະເຫັນດີຕາມຄຳເວົ້ານີ້ເພາະວ່າມັນຍາກອີຫລີການແຂ່ງຂັນກະສູງຂຶ້ນທູກມື້ ເຊິ່ງກ່ອນທີ່ຂ້ອຍຈະໄດ້ LOR ຂ້ອຍໄດ້ສົ່ງໄປທັງໝົດ 7 reports ຫຼັງຈາກຖ້າເປັນເດືອນສະຫຼຸບໄດ້ valid ມາແຕ່ 1 ທີ່ເຫຼືອ Duplicate, ຍັງດີທີ່ເປັນໂຕທີ່ຮຸນແຮງເລີຍພໍເອົາມາຂິງໄດ້.
