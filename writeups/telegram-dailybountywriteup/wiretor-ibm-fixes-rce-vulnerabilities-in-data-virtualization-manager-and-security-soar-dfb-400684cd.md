# 🚨 IBM Fixes RCE Vulnerabilities in Data Virtualization Manager and Security SOAR 🚀🔒

# [WIRE TOR — The Ethical Hacking Services](https://www.linkedin.com/company/wiretor/)

[IBM](https://www.linkedin.com/company/wiretor) has rolled out critical security patches addressing [remote code execution (RCE) vulnerabilities](https://www.linkedin.com/company/wiretor) in its [Data Virtualization Manager](https://www.linkedin.com/company/wiretor) and [Security SOAR](https://www.linkedin.com/company/wiretor) platforms. These updates are crucial to ensure your organization’s data and systems remain secure. 🛡️

# 🐞 The Vulnerabilities

# 1️⃣ CVE-2024–52899 (CVSS Score: 8.5)

- Affected Product: Data Virtualization Manager for z/OS.
- Issue: Malicious JDBC URL parameters could enable arbitrary code execution.
- Resolution: IBM released fix packs for versions 1.1 and 1.2 with step-by-step installation instructions.

# 2️⃣ CVE-2024–45801 (CVSS Score: 7.3)

- Affected Product: Security SOAR.
- Issue: Prototype pollution in the DOMPurify component allows arbitrary code execution or denial-of-service (DoS) attacks.
- Resolution: Vulnerable components were removed in version 51.0.4.0, along with detailed upgrade guidance.

- [Watson Speech Services Cartridge (CVE-2024–49353):](https://www.linkedin.com/company/wiretor) Fixed a high-severity crash issue.
- [OpenSSL Vulnerability (CVE-2024–6119):](https://www.linkedin.com/company/wiretor) Addressed a DoS flaw in Data Observability by Databand.
- [Engineering Lifecycle Management:](https://www.linkedin.com/company/wiretor) Resolved medium- and low-severity flaws, including XSS and credential-related issues.
