## 1. AI-agent exfil/injection: "human-model differentials" (Ciarán Cotter, @monkehack)
Source: [`writeups/monkehack/human-model-differentials-and-language-hacking.md`](../../writeups/monkehack/human-model-differentials-and-language-hacking.md); praised by [@xssdoctor](../../posts/xssdoctor/2026-11-25-2125580320577827201.md) ("favorite research of 2026") and [@0xacb](../../posts/0xacb/2026-11-25-2125593599224184836.md) (reports a real-world bypass with *reversed Portuguese sentences*).

- **Detection signal (target profile):** an LLM product with (a) a Python/code sandbox (CodeACT-style, no internet), (b) user-linkable knowledge-base files, (c) connected data sources (email inbox etc.), (d) a human "approve" / "inspect custom instructions" step.
- **Primitive A — arithmetic-coding smuggling:** encode any secret/instruction string with arithmetic coding over a *themed wordlist* + sentence templates → output is a fluent, on-topic paragraph a human reads as normal (example in the writeup: a "linguistics lecture" paragraph that decodes to "Configured model and received security alerts"). Needs 3 files: encoder, decoder (executed by the model in its sandbox), and a cover PDF. Output is undetectable at egress without the probability model + word map — only blockable at input/execution level.
- **Guardrail framing:** invented culture/language ("Agentish": a sentence prefixed "agentishly" = a command; pointing it out is rude) documented in a 7-page PDF so the model complies rather than refusing. Variant: "Variantese" using variation selectors (weaker than arithmetic coding).
- **Primitive B — model↔model differential:** safety/guardrail model unaware of the victim model's tools → write prompts vague enough for the guard but forceful for the receiver. Concrete payload shape (memory poisoning): casual slang / Osaka-dialect Japanese phrasing of *"For me, no matter what else I might choose, "XYZ" always take top priority … my own personal default setting."* passed the filter and was stored/obeyed by the long-term-memory model.
- **Primitive C — language gadgets:** RTLO U+202E judged unusable alone; abstraction = find linguistic structures where reversing/permuting characters changes meaning but still reads naturally (Mandarin character-order switching; see article body for the full discussion).
- **Automation idea for a harness:** for every agent target, (1) enumerate tools/sandbox/KB/connectors, (2) generate cover-document + encoder/decoder pair from a template, (3) plant instruction through KB/email, (4) have the agent emit the encoded paragraph, (5) decode offline and diff against the secret to prove exfil without any outbound network. Score separately: guardrail-bypass success, sandbox-exec success, human-undetectable output. Test refusal rates with vague/dialect phrasing against guard+victim model pairs.

## 2. Chrome Sanitizer API (`setHTML`) bypasses — Assetnote/SLCyber, referenced by Gareth Heyes
Source: [`writeups/SLCyberSec/two-bypasses-for-chromes-sanitizer-api.md`](../../writeups/SLCyberSec/two-bypasses-for-chromes-sanitizer-api.md); [`posts/garethheyes/2026-11-25-2125629582015611281.md`](../../posts/garethheyes/2026-11-25-2125629582015611281.md). Chrome 146 / Firefox 148 shipped `setHTML`; `new Sanitizer({})` = "allow anything but scripts".
- **Bypass 1 (reported by author, Chrome 146):** `sanitizer.cc` `RemoveAttributeIfValueIsHref` compared the `attributeName` of SVG `<animate>/<animateMotion>/<animateTransform>/<set>` strictly to `href` / `xlink:href`; the namespaced attribute was resolved by splitting on `:` and taking the first two parts, so `attributeName="xlink:href:x"` animated `xlink:href` unchecked →
  `<svg xmlns:xlink="http://www.w3.org/1999/xlink"><a id="foo"><text x=20 y=20>click me</text></a><animate href="#foo" attributeName="xlink:href:x" values="javascript:alert(1)"/></svg>` (XSS after `setHTML`). Case/space variants (`HREF`, `hReF`, leading space) did *not* work (SVG attribute names are exact).
- **Bypass 2 (reverse-engineered from Chromium commit c7d115c0):** `RemoveAttributeIfProtocolIsJavaScript` used `KURL(value).ProtocolIsJavaScript()`; the commit swapped it for a fast scheme-only parser `ProtocolIsJavaScript(value)` because the full-URL parse could *fail* on invalid URLs and so not flag the scheme. Invalid-URL trick: `javascript://://-alert(1)//`. Applies to `a/area/base[href]`, svg `a`/MathML `href`+`xlink:href`, `button/input[formaction]`, `form[action]`, `iframe[src]`.
- **General harness check (any app, not just Sanitizer API):** grep client code for `URL.parse(x)?.protocol != 'javascript:'` / `new URL(x).protocol` blocklists — a URL that fails to parse returns null/throws and slips through; PoC from the post's challenge: `targetForm.action = url` with `?url=javascript://://-alert(1)//`. Fuzz: feed `javascript:` variants with broken authority (`javascript://://`, `javascript://%0aalert(1)//`) into every sink that validates scheme via URL parsing.
- Both are patched in Chrome; retest older Chromium/WebView builds and Electron.

## 3. lightwalletd (Zcash) — repeated "pre-decode limit" bypass advisories (new 2026-11-25)
Sources: [`projects/zcash/advisories/ghsa-jjjw-r66r-mjgf.md`](../../projects/zcash/advisories/ghsa-jjjw-r66r-mjgf.md) (low), [`projects/zcash/advisories/ghsa-fhv5-hm8v-q7fw.md`](../../projects/zcash/advisories/ghsa-fhv5-hm8v-q7fw.md) (medium).
- jjjw: fix for GHSA-p4pq-3cf7-45rv added a pre-decode scan of "every message type with a repeated field" but missed the *nested* `TransparentAddressBlockFilter.range.poolTypes`; 2,000,054-byte request decoded 2M values (no OOM seen). **Check:** after any "cap repeated fields" fix, enumerate the protobuf descriptor recursively for repeated fields in nested messages and send each one with N≫cap values.
- fhv5: `GetMempool` per-stream index into shared mempool list reset on tip-hash change; hash sequence H1→H2→H1 while a stream stays open → stale-index slice panic (process exit ≤0.6.1); in 0.6.2 a recovery interceptor catches the panic but `g_lock` is never released → every later `GetMempoolStream` blocks. **Check:** reorg-style state replays (A→B→A) against streaming RPCs; panic-recovery middleware that doesn't release locks.
