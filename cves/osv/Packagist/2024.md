### DRUPAL-CONTRIB-2024-002 — 
- Aliases: CVE-2024-13238 | Published: 2024-01-10 | Modified: 2026-09-10 | Severity: None
- Affected Packagist:https://packages.drupal.org/8/drupal/typogrify: introduced:0 fixed:1.3.0

The Typogrify module brings the typographic refinements of Typogrify to Drupal. It provides a text filter and a Twig filter.

The typogrify Twig filter can be used to bypass the Twig auto-escape feature, leading to a persistent Cross Site Scripting (XSS) vulnerability.

This vulnerability is mitigated by the fact that it is only exposed when the twig filter is specifically used in a template to render content.

This module has multiple vulnerabilities due to the requirements on the routes it provides not being restrictive enough.

### DRUPAL-CONTRIB-2024-076 — 
- Aliases: CVE-2024-13312 | Published: 2024-12-11 | Modified: 2026-03-18 | Severity: None
- Affected Packagist:https://packages.drupal.org/8/drupal/social: introduced:11.8.0 fixed:12.3.10 | introduced:12.4.0 fixed:12.4.9

Open Social is a Drupal distribution for online communities, which ships with a default (optional) module social\_file\_private to ensure the images and files provided by the distribution are stored in the private instead of the public filesystem.

For installations of Open Social prior to version 11.8.0, after updating to 11.8.0 or higher, newly uploaded files were no longer stored in the private file system as intended. Instead, they were stored in the public file system.
