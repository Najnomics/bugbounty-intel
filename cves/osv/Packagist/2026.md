- Aliases: BIT-drupal-2026-6366, CVE-2026-6366, GHSA-xmjc-63pr-2mpg | Published: 2026-04-15 | Modified: 2026-09-10 | Severity: None
- Affected Packagist/drupal/core: introduced:8.0.0 fixed:10.5.9 | introduced:10.6.0 fixed:10.6.7 | introduced:11.0.0 fixed:11.2.11 | introduced:11.3.0 fixed:11.3.7 versions: 10.0.0, 10.0.0-alpha1, 10.0.0-alpha2, 10.0.0-alpha3, 10.0.0-alpha4, 10.0.0-alpha5, 10.0.0-alpha6, 10.0.0-alpha7, 10.0.0-beta1, 10.0.0-beta2, 10.0.0-rc1, 10.0.0-rc2, 10.0.0-rc3, 10.0.1, 10.0.10, 10.0.11, 10.0.2, 10.0.3, 10.0.4, 10.0.5

Drupal core contains a chain of methods that could be exploitable when an insecure deserialization vulnerability exists on the site. This so-called "gadget chain" presents no direct threat, but is a vector that can be used to achieve remote code execution or SQL injection if the application deserializes untrusted data due to another vulnerability.

This issue is not directly exploitable.

This issue is mitigated by the fact that in order for it to be exploitable, a separate vulnerability must be present to allow an attacker to pass unsafe input to `unserialize()`. There are no such known exploits in Drupal core.
