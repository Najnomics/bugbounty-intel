**Bugs (F5 release of 18 Nov 2026, fixed in nginx 1.31.9):** CVE-2026-123007 HTTP/2 `send_window` flow-control integer underflow → invalid memcpy → RCE on a plain static-file server with HTTP/2 (1.9.5–1.31.8); CVE-2026-123633 HTTP/2 connection use-after-free when `proxy_pass` upstream connection slots run low (1.19.7–1.31.8); CVE-2026-121810 HTTP/3 UAF as proxy; CVE-2026-123634 DNS-resolver UAF when the upstream host is request-derived (`resolver` + variable `proxy_pass` + `mirror`/SSI subrequests); CVE-2026-113425 mail-proxy UAF (`auth_http`). Found independently by Wiz (Wiz Atlas AI harness), Ikotas Labs/Satoki (with OpenAI), Metnir, Rapid7, Xint (fully automated scan found 4 of 5).
**Harness checks (in-scope assets only, non-destructive):**
1. Fingerprint nginx (`Server: nginx/x.y.z`, default error pages) and record version; flag 1.9.5–1.31.8 (but distro backports keep old version strings — Ubuntu 22.04 `1.18.0`, Debian 12 `1.22.1` — so treat version as a lead, not proof).
2. Detect HTTP/2 via ALPN: `curl -sI --http2 https://host -o /dev/null -w '%{http_version}'` or `openssl s_client -alpn h2 -connect host:443 </dev/null 2>/dev/null | grep 'ALPN protocol'`; HTTP/3 via `Alt-Svc: h3=`.
3. Reverse-proxy indicators (upstream headers like `X-Upstream`, `Via`, mixed backends) raise CVE-2026-123633 likelihood; request-derived upstreams (open-proxy style `proxy_pass http://$host`/`$arg_*`) raise CVE-2026-123634.
4. Never send crash/heap-grooming payloads to production; report version+h2 exposure only where the program accepts "outdated software with public critical CVE" reports, otherwise use as prioritisation signal.
5. Albinowax's angle: teams disabling HTTP/2 as mitigation fall back to HTTP/1.1 front-ends → re-run request-smuggling scans (HTTP Request Smuggler / CL.TE, TE.CL, H2-downgrade probes) against targets whose ALPN changed from h2 to http/1.1 since the last snapshot.
