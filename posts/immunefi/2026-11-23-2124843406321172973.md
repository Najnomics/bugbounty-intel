> If you want to know how AI will change software security over the next two years, look at crypto’s early days.
>
> Early DeFi was open-source contracts holding huge amounts of money, often unaudited and readable by anyone. Every day was hack day. If money sat in code someone could read, attackers had every reason to find the bug.
>
> Some teams tried to hide by not verifying their contracts, betting nobody would bother reading raw bytecode. It bought time. But unverified contracts still got exploited, and even MEV bots running private strategies got drained.
>
> AI is now bringing the same problem to traditional software.
>
> When a model can analyze a patch diff, reverse-engineer a binary, or understand decompiled bytecode, hiding the source code stops being a barrier. Work that once took skilled researchers days can now be done by machines at scale. And when there’s money in finding bugs, attackers will use them.
>
> Web2 is less ready for this than it thinks.
>
> Crypto made source code review part of shipping. Most web2 security testing is black-box: probing running applications from the outside. Ask a web2 hacker to do a source code review and they’ll look at you funny.
>
> We’ve seen this firsthand. When we opened up a source code review of a 23,000-line web application with $30K in rewards, the scarce resource wasn’t money. It was web2 researchers trained to read source code. Our smart contract audit competitions regularly draw over 900 researchers.
>
> AI is already finding zero-days in traditional software. When AI agents scanned 2,849 recently deployed smart contracts, the only new bugs they found were basic mistakes in small tokens worth less than $4,000 combined. That’s a limited study and doesn’t prove crypto is more secure. But crypto learned early that code holding money attracts people willing to inspect every line, and built audits, bug bounties, and continuous testing around that fact.
>
> The rest of software is about to learn the same lesson. The next two years will be rough. Now is the time to take security seriously and fix everything that shipped with zero security reviews.
