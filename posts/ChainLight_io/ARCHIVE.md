    > This is a clever attack. In the vulnerable contract Vault (https://etherscan.io/address/0xb91ae2c8365fd45030aba84a4666c4db074e53e7) there is a uniswapV3SwapCallback function that uses transient storage to verify the caller. Specifically, it loads an address of a Uniswap pool from the slot 0x1 and checks that it matches msg.sender. It looks right at the first glance, however at the end of the execution uniswapV3SwapCallback stores the value of the variable amount at the same slot!
