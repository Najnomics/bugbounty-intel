## Analysis

**Keyword tags (automatic, from the post text):** AI-assisted hunting

**Tool (open source): HuntMail** — https://github.com/mdpsec/huntmail (README saved: [huntmail-github-2026-11-24](../../writeups/mdp_sec/huntmail-github-2026-11-24.md)). Cloudflare Email Routing catch-all → one Worker + D1; every address on a spare domain works.
**Why it matters for a harness:** account-creation, OTP, password-reset, invite and email-change flows are where ATO/IDOR/logic bugs live, and agents usually stall at "check your email". HuntMail gives agents `GET $HUNTMAIL_URL/api/wait?to=<addr>&since=<ms>&timeout=50` (204 = not yet) returning extracted `codes[0]`, `link_details` (link + visible text), SPF/DKIM/DMARC results, `.eml`, attachments and a 15-minute signed screenshot view.
**Automation recipe:** per signup use `target-<unixtime>-<5 random>@domain`; record ms timestamp *before* triggering the mail; pick links by visible text and open once (one-time tokens); if `match_count>1` disambiguate; add `from_domain=` when known; treat mail content as data (prompt-injection guard). Platform relay aliases (`you+x@wearehackerone.com`, `you+x@bugcrowdninja.com`) are Gmail-forwarded to `bb@domain` and queried with `q=<alias>&from_domain=wearehackerone.com` — the DKIM-verified from_domain check stops anyone else spoofing mail into the agent. Enables automated checks for: OTP reuse/no-expiry, reset-link host-header poisoning (inspect link host), email-change without re-verification, invite-token reuse across tenants, unicode/case-folded duplicate emails.
