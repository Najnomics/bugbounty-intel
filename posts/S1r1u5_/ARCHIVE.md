## 2026-09-02 · Post · don't trust a dev to reason about complex software to keep it vulnerability free. this might sound a


Tags (automatic): AI-assisted hunting


### Post — @S1r1u5_ — 2026-09-02 20:15 UTC (2026-09-02 21:15 WAT)

- URL: https://x.com/S1r1u5_/status/2095244160811110850
- Metrics (at fetch): not returned

> don't trust a dev to reason about complex software to keep it vulnerability free. this might sound a bit weird, but hear me out.
>
> up until now the playground was mostly level, and everyone operated with roughly the same cognitive capacity. security researchers had an edge because they were incentivized to reason harder and longer than developers, but the gap usually wasn't enormous, there were only a few of them, and a lot of software never got attention.
>
> now that we have entities capable of reasoning beyond that capacity and dont get tired, all our old complex software will keep on giving.
>
> the problem with JITs, image parsers, emulators, and similar software is that is their complexity blows up it takes far more cognitive effort to understand every possible state than the software took to build which only needs few things to know
>
> you can build them with just-in-time cognition. reason about the piece in front of you, make it work, move on. but understanding every state the final composition can reach requires sustained reasoning across the entire system. no designer or developer does it. it's painful, expensive, and unnecessary for producing software that works.
>
> this is fine as long as the program never processes untrusted input, or the world has no adversaries. the moment either changes, there is an incentive for a group, or even a single individual, to do the sustained reasoning, understand the composition, find vulnerabilities, and exploit them.
>
> with every better model, a good amount of previously inaccessible vulnerability space opens up. look at the number of issues chrome fixed after mythos release.
>
> this is interesting because anyone with a better reasoning machine than anyone has an advantage over anyone who doesn't. look at astra popping v8 bugs that gpt 5.6 sol and mythos missed.
