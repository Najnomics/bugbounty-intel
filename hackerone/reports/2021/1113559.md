# H1 #1113559: Japan - CSRF in webapp.starbucks.co.jp with user interaction could leak an access token if the user was not using Chrome

- URL: https://hackerone.com/reports/1113559
- Program: starbucks (Starbucks)
- Reporter: elber
- Weakness: Cross-Site Request Forgery (CSRF)
- Severity: high (score 7.1; metrics {"attack_vector": "network", "attack_complexity": "low", "privileges_required": "none", "user_interaction": "required", "scope": "unchanged", "confidentiality": "high", "integrity": "low", "availability": "none"})
- Bounty: yes
- Asset: URL login.starbucks.co.jp
- State: Closed/resolved | Submitted: 2021-03-01 | Disclosed: 2021-05-18
- CVE: -

## Summary (team, by agedsumatra)

elber discovered a CSRF in webapp.starbucks.co.jp leaked an access token if an authenticated user opened a crafted HTML file in a browser other than Chrome which has Same Site Attribute for the cookie set by default.

elber also demonstrated the ability to add a Starbucks card to the account with the potential for a single account takeover at login.starbucks.co.jp, if the attacker could trick the user into executing another crafted HTML file.

elber — thank you for reporting this vulnerability and for confirming the resolution.
