# H1 #269318: Bypass of Rate limiting in secure_session endpoint's password input will lead to user password disclosure 

- URL: https://hackerone.com/reports/269318
- Program: moneybird (Moneybird)
- Reporter: 0xprial
- Weakness: Improper Restriction of Authentication Attempts
- Severity: None (score None; metrics null)
- Bounty: yes
- Asset: None None
- State: Closed/resolved | Submitted: 2017-09-18 | Disclosed: 2021-05-06
- CVE: -

## Summary (team, by edwin)

The rate limit for entering a password to start a secure session was too low. This allowed for brute force password guessing when an attacker would gain access to an existing session of a user. We have solved the issue by making the password rate limit the same as the regular login procedure.

## Summary (researcher, by 0xprial)

Bypassing the rate-limiting by setting Throttle value 0 to 5000 in **Burp Suit tools** `Intruder's` request engine option.
