# H1 #260468: first name and last name restrictions bypass

- URL: https://hackerone.com/reports/260468
- Program: legalrobot (Legal Robot)
- Reporter: flashdisk
- Weakness: Incorrect Calculation of Buffer Size
- Severity: none (score None; metrics null)
- Bounty: yes
- Asset: URL app.legalrobot.com
- State: Closed/resolved | Submitted: 2017-08-15 | Disclosed: 2017-09-05
- CVE: -

## Summary (team, by danrubins)

A security researcher discovered that the maximum lengths of the first name and last name fields were set to 32 characters at registration and 50 characters when using the profile update form. There was no security impact and no sensitive data was compromised. Thanks to @flashdisk for pointing out this inconsistency!
