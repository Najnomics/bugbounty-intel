## Summary (team, by departmentofdefense_2)

A remote command execution (RCE) vulnerability was found on a DoD website which could have enabled an attacker to execute remote commands on the web server. @wrench, and other researchers were able to demonstrate this vulnerability by crafting a specially formatted URL.
