# Vulnerability

## Vulnerability Description

Urls are not properly escaped before concatenating them into the command that is opened using `exec()`.

## Steps To Reproduce:

```js
require("open")("http://example.com/`touch /tmp/tada`");
```

Observe `/tmp/tada/` file created.
