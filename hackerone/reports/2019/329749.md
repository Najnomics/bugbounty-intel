- Weakness: Cross-Site Request Forgery (CSRF)
- Severity: high (score 8.8; metrics {"attack_vector": "network", "attack_complexity": "low", "privileges_required": "none", "user_interaction": "required", "scope": "unchanged", "confidentiality": "high", "integrity": "high", "availability": "high"})

- State: Closed/resolved | Submitted: 2018-03-25 | Disclosed: 2019-04-28
- CVE: CVE-2019-5430

## Summary (team, by ubnt-rubens)

In UniFi Video 3.10.0, due to the lack of CSRF protection, it is possible to abuse the Web API to make changes on the server configuration without the user consent, requiring the attacker to lure an authenticated user to access on attacker controlled page.
