## Summary (team, by revive-mcp)

## Description

HackerOne community member Kaushalendra Dubey (titanrain) reported that the zone banner-linking page did not cast the keys of the submitted banner-selection array to integers. A manager, or a website user with permission to link banners to zones, who owned the selected website and zone could place SQL in an array key, which was concatenated unquoted into the banner-lookup query. This allowed time-based blind SQL injection as the application's database account. The single-banner link path on the same page was already integer-constrained and was not affected.

## Resolution

Zone banner linking now accepts only positive integer keys in the banner-selection array; any other key is discarded before the value reaches the data-access layer, so a crafted key can no longer alter the lookup query.
