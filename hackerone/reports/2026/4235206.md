## Summary (team, by revive-mcp)

## Description

HackerOne community member Le Ngoc Thuan (h2w) reported reflected XSS through the ct0 request parameter, used to pass a third-party click tracking URL to the delivery scripts. The value only had to start with http:// or https:// and was prepended unescaped to the click URL. An unauthenticated attacker could craft a delivery URL that executes JavaScript in the delivery origin when visited. Exploitation requires an active banner whose HTML uses the raw {clickurl} macro; the {clickurl_html} and {clickurl_enc} macros escape the value and are not affected.

## Resolution

The ct0 parameter is now ignored unless it is an HTTP or HTTPS URL made only of characters that cannot break out of the banner markup. Quotes, fragments and HTML entities are not accepted.
