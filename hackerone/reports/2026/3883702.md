## Summary (team, by pink23)

DNS Rebinding Enables Unauthorized MCP Tool Access was reported to IBM, analyzed and has been remediated. Thank you to our external researcher @avishaigonen.



## Summary (researcher, by avishaigonen)

The IBM watsonx.data MCP server exposes Streamable HTTP at `/mcp` without an inbound caller secret or effective Host/Origin validation. A malicious web page can use DNS rebinding to keep the attacker origin while its hostname resolves to `127.0.0.1`, initialize the local MCP session, enumerate tools, and invoke watsonx.data-backed tools through the server-held IBM IAM credential path. The attached demo uses fake watsonx.data data, but it runs the genuine upstream MCP server path and proves the browser-origin request reaches tool dispatch and the server-held backend authorization path.
