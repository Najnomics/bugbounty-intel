## Summary (team, by jonp)

Admin permissions on a game hub could be leveraged to view UGC reports on unrelated games.

## Summary (researcher, by creekie)

If an account had admin permissions on a game hub, he'd be able to view other game hubs UGC reports by simply making the appid parameter the appid of the game hub he has admin permissions on.
