## Summary (researcher, by ian)

@shubs and I discovered an instance of Flyte Console on uberinternal.com. After auditing the open source code, we noticed an unauthenticated route for a “CORS proxy”. This was a classic server-side request forgery issue, allowing us to pass an arbitrary request to be performed by the server and read the response. This also allowed reflected cross-site scripting as we could proxy arbitrary HTML documents through it.

We reported this to both Uber and Flyte, where it was assigned CVE-2022-24856 and quickly resolved.
