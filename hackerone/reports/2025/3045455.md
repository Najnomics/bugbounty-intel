## Summary (team, by gus_tabares)

A reflected cross-site scripting (XSS) vulnerability was found on files stored on an Autodesk AREA server, which could have allowed an attacker to inject malicious JavaScript code when viewed by users. Autodesk has fixed the vulnerability and we thank @ahmednasr1 for reporting this issue.
