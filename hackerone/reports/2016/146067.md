# H1 #146067: Read-only share recipient can restore old versions of file

- URL: https://hackerone.com/reports/146067
- Program: nextcloud (Nextcloud)
- Reporter: bugdiscloseguys
- Weakness: Improper Authentication - Generic
- Severity: None (score None; metrics null)
- Bounty: $300
- Asset: None None
- State: Closed/resolved | Submitted: 2016-06-20 | Disclosed: 2016-07-19
- CVE: CVE-2016-9462

## Summary (team, by lukasreschke)

The restore capability of Nextcloud was not verifying whether an user has only read-only access to a share. Thus an user with read-only access was able to restore old versions.

A detailed advisory can be found at https://nextcloud.com/security/advisory/?id=nc-sa-2016-005.
